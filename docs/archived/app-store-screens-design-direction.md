# BAM Labs – App Store Screenshots Design Direction

## Current State
- Static, flat phone mockups
- Dark background (matches app UI)
- Text centered above each phone
- All phones at same angle and size

## Goal
Make the screenshots feel **premium, dynamic, and editorial** — like a luxury fitness brand, not a utility app.

---

## Design Direction: "Editorial Fitness"

### Concept
Treat each screenshot like a magazine spread. Mix bold typography, dynamic device angles, and intentional negative space. The dark UI of the app provides contrast — let the framing around it create visual energy.

---

## Visual System

### Colors

| Element | Color |
|---------|-------|
| Background (base) | #1A1A1A (charcoal) or #0D0D0D (near black) |
| Background (accent) | Subtle warm gradient toward bronze/gold |
| Text (headlines) | #F5F0E6 (warm cream) |
| Text (descriptions) | #A89F91 (muted tan) |
| Accent lines/glows | #C9A96E (gold) or #E8DCC4 (light cream) |

### Typography

| Element | Style |
|---------|-------|
| Headlines | Bold sans-serif (SF Pro Display Bold, or similar) |
| Size | Large — 48-64pt equivalent at 1284px width |
| Descriptions | Regular weight, smaller — 24-28pt |
| Alignment | Left-aligned for most, centered for Focus screen |

### Device Mockups

| Style | Notes |
|-------|-------|
| Frame | Space Black iPhone 15 Pro (matches app's dark UI) |
| Angles | Vary between screens: 0°, 15°, 25°, -15° |
| Scale | Some phones cropped at edges for dynamism |
| Shadows | Soft, diffused — not harsh drop shadows |

### Texture & Effects

- Subtle grain overlay (2-4% opacity) for premium feel
- Soft glow behind phones (not neon — more like ambient light)
- Occasional line elements (thin gold strokes) for visual rhythm

---

## Composition Principles

1. **Vary the rhythm** — Don't repeat the same layout twice in a row
2. **Create entry points** — Lead the eye with angles and typography
3. **Use negative space** — Let the dark backgrounds breathe
4. **Maintain hierarchy** — Headline > Phone > Description
5. **End strong** — Final screen should feel like a conclusion
